# ブラウザ拡張 {#browser-extension}

この拡張機能は、ブラウザに小さなボタンと右クリックの項目をいくつか加え、見ているものを積み場へ送ります。
**ページ**・**選択範囲**・**リンク**・**画像**です。**Chrome・Edge・Brave**(Chromium 系すべて)と **Firefox** で、
Manifest V3 の拡張機能として動作します。

通信先は同じコンピューター上の tsumiba アプリだけで、`127.0.0.1` を使います。どのサーバーにも何も
送られません([プライバシーとセキュリティ](privacy-and-security.md))。

> [!NOTE]
> この拡張機能は、Chrome ウェブストア、Edge アドオン、addons.mozilla.org にはまだ公開されていません。
> 今のところは、リリースページの zip から読み込みます。Mozilla の署名がないため、Firefox では
> ブラウザを再起動するまでしか保持されません(下記)。

> [!WARNING]
> **どこまで試験されているか。**この拡張機能は、ヘッドレスの Chromium(サービスワーカー、メニュー、
> ショートカット、ポップアップ、オプションページ)で動作を確認し、Firefox 版は `web-ext lint` で検査
> しました。**Firefox・Edge・Brave では一度も実行しておらず**、ヘッドレスではない実際の Chrome でも
> 試していません。粗いところがあるかもしれません。見つけたら[ぜひ報告してください](https://github.com/hjosugi/tsumiba/issues)。

## インストール {#install}

[リリースページ](https://github.com/hjosugi/tsumiba/releases/latest)から、お使いのブラウザ用の zip を
ダウンロードします。`tsumiba-extension-chrome-<version>.zip` または
`tsumiba-extension-firefox-<version>.zip` です。

**Chrome・Edge・Brave**

1. ずっと置いておける場所に展開します(ブラウザはそこからファイルを読みます)。
2. `chrome://extensions` を開きます(Edge は `edge://extensions`、Brave は `brave://extensions`)。
3. **デベロッパー モード**をオンにします。
4. **パッケージ化されていない拡張機能を読み込む**を選び、展開したフォルダーを指定します。

**Firefox**

1. `about:debugging#/runtime/this-firefox` を開きます。
2. **一時的なアドオンを読み込む…**を選び、zip(または展開したフォルダー内の `manifest.json`)を指定します。
3. 一時的なアドオンは、Firefox を終了すると取り除かれます。署名済みの版が公開されるまでは、再起動のたびに
   読み込み直してください。Firefox のリリース版は Mozilla が署名したアドオンしか保持しないため、今すぐ
   恒久的に使うには、Firefox Developer Edition・Nightly・ESR で `xpinstall.signatures.required` を
   `false` にする必要があります。Firefox 128 以降が必要です。

ポップアップを開けるよう、拡張機能のボタンをツールバーにピン留めしておくと便利です。

**自分でビルドする:**チェックアウトしたリポジトリで `node extension/build.mjs` を実行します(`zip` プログラムが
必要です)。`extension/dist/tsumiba-extension-chrome-<version>.zip`、
`extension/dist/tsumiba-extension-firefox-<version>.zip`、そして展開済みのフォルダーが書き出されます。

## 最初に 1 回だけペアリング {#pair-it-once}

拡張機能が、あなたの tsumiba と通信してよいことを示す**トークン**が必要です。トークンが無いと、何も
送られません。

1. tsumiba を起動します。
2. トークンを取得します。ターミナルで `tsumiba token` を実行するか、tsumiba の
   **設定 → ブラウザ拡張 → コピー**を使います。
3. 拡張機能の**オプション**(ボタンを右クリック →「オプション」、またはポップアップの「設定」)を開き、トークンを
   貼り付けます。**ポート**(既定は `47821`。tsumiba の*設定 → ブラウザ拡張*と同じ値)を確認して、
   **保存**を押します。
4. **接続をテスト**を押します。うまくいくと「tsumiba 0.1.0 に接続できました。」と表示されます。

トークンはブラウザの拡張機能用ストレージに保存され、コンピューターの外へは出ません。再生成した場合
(`tsumiba token --regenerate`、または設定の**再生成**)は、すべてのブラウザで再ペアリングが必要です。

## 使い方 {#using-it}

### 右クリック {#right-click}

| 右クリックする対象 | 選ぶ項目 | 保存されるもの |
| --- | --- | --- |
| 選択したテキスト | **選択範囲を tsumiba に送る** | 新しいメモ:テキストを Markdown の引用にし、続けてページへのリンク |
| リンク | **リンクを tsumiba に送る** | 新しいメモ:リンクのテキストを見出しに、アドレス、そして「From:」にページ |
| 画像 | **画像を tsumiba に送る** | 画像そのものを、積み場のファイルとして(取得元はそのページ) |
| ページ | **ページを tsumiba に送る** | 新しいメモ:タイトルを見出しに、続けてアドレス |

結果はツールバーのボタンに表示されます。成功は緑の ✓、問題があれば赤の !で、理由はツールチップに出ます。

選択範囲から作られるメモは、次のような形になります。

```markdown
> The shelf slides in from the top edge of the screen
> and goes away when you do.

[tsumiba documentation](https://hjosugi.github.io/tsumiba/ja/)
```

### ポップアップ {#the-popup}

ツールバーのボタンをクリックすると、次のものが使えます。

- **接続状態:**接続済み(バージョンと件数つき)、未ペアリング、tsumiba が起動していない、トークンの不一致。
- **クイックメモ:**書いて、**メモを保存**(またはボックスの下に表示されるショートカット)。
- **このページを保存**と**選択範囲を保存**。
- **積み場を開く**:起動中の tsumiba に表示を依頼します。

### キーボード {#keyboard}

<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> で、現在のページを送ります。ブラウザの拡張機能のショートカット設定
(`chrome://extensions/shortcuts`。Firefox は `about:addons` の歯車メニュー →「拡張機能のショートカットを管理」)
で変更できます。

## ほかのサイトの画像 {#images-from-other-sites}

画像そのものを保存するには、ブラウザがその画像を元のサイトからダウンロードしなければならないことがあり、
拡張機能はそのサイトへのアクセス権が無いとそれができません。それが最初に失敗したとき、拡張機能は**一度だけ**
すべてのサイトへのアクセスを求め、「画像を tsumiba に送る」を選んだときにだけそれを使います。断った場合は
それを記憶し、画像の代わりに画像の**アドレス**をメモとして保存します。あとからアクセスを許可することも、
取り消すことも、拡張機能のオプションの「他サイトの画像」でできます。

送る前に、拡張機能は tsumiba にアップロード上限(`storage.max_upload_mb`)を尋ねます。それを超える画像は、
送ってから断られるのではなく、分かりやすいメッセージとともに手元で拒否されます。

ページに埋め込まれた画像(`data:` URL)は、そのまま読み取れます。`blob:` の画像は、作ったページのものなので外からは
読めず、アドレスだけが保存されますが、そのページの外ではあまり役に立ちません。

## 権限 {#permissions}

| 権限 | 理由 |
| --- | --- |
| `contextMenus` | 4 つの右クリック項目 |
| `storage` | ポートとトークンをこのブラウザプロファイルに保存する |
| `activeTab`、`scripting` | 操作したときに、現在のタブのタイトルとアドレス(ポップアップからは選択範囲も)を読む |
| `http://127.0.0.1/*`、`http://localhost/*` | このコンピューター上の tsumiba と通信する |
| *任意:*すべてのサイト | 画像そのものを取得する(上記)。必要なときにだけ求められる |

拡張機能は、ほかのネットワーク通信を一切行いません。解析も、独自の更新確認もありません。

## トラブルシューティング {#troubleshooting}

| ポップアップやバッジの表示 | 意味と対処 |
| --- | --- |
| *ペアリングが未設定です* | トークンが保存されていません。「最初に 1 回だけペアリング」の手順に従ってください。 |
| *tsumiba が起動していません* | tsumiba を起動してください。起動しているのに出る場合はポートを確認してください。既定のポートが使用中だと、tsumiba は別のポートを選んで通知します(**設定 → ブラウザ拡張**に表示されます)。そのポートを拡張機能のオプションに入れてください。 |
| *トークンが一致しません* | トークンが変わっています(再生成した、またはデータフォルダーが別)。もう一度コピーしてください。 |
| *tsumiba ではありません* | そのポートでは別のプログラムが応答しています。両方のポートを変更してください。 |
| *tsumiba に拒否されました* | サーバーが「禁止」と答えました。ポートを確認してください。 |
| *tsumiba のアップロード上限を超えています* | `storage.max_upload_mb` を上げてください([設定](configuration.md#storage))。 |
| ショートカットが効かない | ほかの拡張機能やシステムが <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> を使っている可能性があります。ブラウザの拡張機能のショートカット設定で変更してください。 |
| Firefox:理由が分からず送れない | Firefox はホストの権限を任意のものとして扱います。`about:addons` → tsumiba →「権限」を開き、`127.0.0.1` へのアクセスを許可してください。 |
| 画像がファイルではなくリンクとして届く | ブラウザが取得できず、すべてのサイトへのアクセスも拒否された(またはサイトがスクリプトからの取得を拒否した)場合です。オプションの「他サイトの画像」で許可してください。 |

tsumiba の設定で**ブラウザ拡張とコマンドラインを受け付ける**をオフにしていると、API 自体が動いていないので、
ここからは何も接続できません。
