# tsumiba {#tsumiba}

**メモとファイルを、画面の端にひと積み。**

tsumiba(積み場)は、画面の上端からスライドして現れる、メモとファイルの置き場です。ポインターを上端に
置くか、ショートカットを押すと、パネルが降りてきます。メモを書き、ファイルをドロップして、元の作業へ
戻る。用が済めば自分で引っ込み、隠れている間は何も消費しません。

**Windows・macOS・Linux** で動作する、Rust 製の MIT ライセンスのソフトウェアです。

## 何であるか、何でないか {#what-it-is-and-what-it-is-not}

tsumiba は、[Unclutter](https://unclutterapp.com/) の中でもよく使われる部分を、あらゆるデスクトップ向けに
作り直したものです。macOS 専用の Unclutter には、クリップボード履歴・ファイルのドロップゾーン・メモという
3 つのパネルがあります。tsumiba が持つのは**メモとファイルの 2 つだけで、これは意図した選択です。**
クリップボードマネージャーはありません。

そこに、見ているページ・選択範囲・リンク・画像を積み場へ送る**ブラウザ拡張**と、スクリプトから使える
**コマンドライン**が加わります。

| | |
| --- | --- |
| **メモ** | 普通の Markdown ファイル。入力するそばから保存され、検索でき、ピン留めもできます。積み場を開くと空のメモが待っているので、すぐ書き始められます。 |
| **ファイル** | 何でもドロップできます。コピーを保存することも、元の場所だけを覚えておくこともできます。画像はサムネイル表示。削除したものは 30 日間ゴミ箱に残ります。 |
| **ブラウザ拡張** | Chrome・Edge・Brave・Firefox 対応。右クリック →「tsumiba に送る」、またはポップアップでクイックメモ。 |
| **コマンドライン** | `tsumiba note "牛乳を買う"`、`tsumiba add report.pdf`、`tsumiba list --json`。アプリが起動していてもいなくても使えます。 |
| **ローカルで、プライベート** | アカウントも、クラウドも、テレメトリもありません。待ち受けるのは `127.0.0.1` だけで、トークンで守られています。 |
| **日本語と英語** | 表示言語はシステムの言語に従います。ライト/ダークのテーマもシステムに従います。 |

## 現状について正直に {#an-honest-status}

これは**バージョン 0.1.0** です。何を確かめ、何をまだ確かめていないかは
[対応プラットフォーム](platforms.md)に書いてあります。要点は次のとおりです。

- ウィンドウ、画面上端のトリガー、ショートカット、上端へのドラッグは、**Linux(X11)**の仮想ディスプレイ上で
  端から端まで動作を確認しました。
- **Windows と macOS** のビルドは CI でコンパイル・lint・テストされています(保存層、HTTP API、
  コマンドラインを含む)。ただし、ウィンドウ・トレイ・ショートカットの挙動は**実機ではまだ確認していません**。
- **Wayland** ではアプリケーションがポインターを監視することも、キーを捕まえることもできないため、
  積み場は通常のウィンドウになります。`tsumiba toggle` を自分でキーに割り当ててください。
- **積み場からほかのアプリへファイルをドラッグして取り出すことは、まだできません。**
  理由と代わりの方法は[ファイル](files.md)にあります。
