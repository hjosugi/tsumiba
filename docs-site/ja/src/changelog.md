## 0.1.0:最初のリリース(2026 年 10 月 17 日) {#v0-1-0}

**追加**

- **積み場:**一度だけ、隠れた状態で作られ、モニターの上端からスライドして現れるウィンドウ。隠れている間は
  タイマーを持たず、何も処理しません。
- **呼び出し:**ポインターを上端の中央に留める(既定 250 ms)、何かを上端までドラッグする(すぐに開く)、
  グローバルショートカット(`Ctrl+Alt+Space`)、トレイアイコン、`tsumiba toggle`。
- **メモ:**メモ 1 つにつき 1 つの Markdown ファイル、最後のキー入力の 0.5 秒後に保存、ピン留め、検索、
  元に戻せる削除。積み場を開くと空のメモが始まります。
- **ファイル:**積み場にファイルやフォルダーをドロップ。専用のコピーを保存するか、場所だけを覚える
  (フォルダーは常に場所だけ)。画像のサムネイル、開く、フォルダーで表示、ファイルをコピー、パスをコピー、
  コピーを保存、名前の変更、ピン留め、外す。外した項目は 30 日間ゴミ箱に残ります。
- **設定画面**と `config.toml`:言語(English、日本語)、テーマ、ログイン時に起動、パネルのサイズと表示する側、
  ショートカット(押して記録)、上端トリガーとその待ち時間、コピーかリンクか、ブラウザ API のポートと
  トークン。
- **コマンドライン:**`note`・`add`・`list`・`show`・`hide`・`toggle`・`quit`・`token`・`paths`・`serve`。
  起動中のアプリがあればそれを使い、無ければファイルを直接扱います。
- トークンで守られた `127.0.0.1` の**ローカル HTTP API**。DNS リバインディングとクロスサイトのリクエストを
  拒否する Host と Origin の検査つき。
- Chrome・Edge・Brave・Firefox 向けの**ブラウザ拡張**:選択範囲・リンク・画像・ページを送る、ポップアップの
  クイックメモ、ペアリングのあるオプション。
- 日本語がそのまま表示されます。システムの CJK フォントを見つけ、フォールバックとして使います。
- 配布物:Windows の zip、macOS のユニバーサル `.app`(zip と dmg)、Linux の tar.gz、Nix の flake、
  チェックサムを検証する `install.sh` / `install.ps1`。

**既知の制限**

- 積み場からほかのアプリケーションへファイルをドラッグして取り出すことは、サポートしていません。
- Wayland では、積み場は上端トリガーもグローバルショートカットも無い通常のウィンドウです。
- Windows と macOS のビルドは CI で作成・テストされていますが、ウィンドウ・トレイ・ショートカットの挙動は
  実機ではまだ確認していません。
- リリースはコード署名(Windows)も公証(macOS)もされていません。
