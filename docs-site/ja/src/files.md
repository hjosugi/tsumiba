## ファイルを追加する {#adding-files}

- 積み場のどこにでも、ファイルやフォルダーを**ドロップ**します。ドラッグ中はオーバーレイが強調表示されます。
- **ファイルを追加…** で、システムのファイルダイアログが開きます。
- **上端へドラッグ:** 積み場が隠れているときに、ファイルを上端までドラッグするとすぐに開くので、そのまま
  ドロップできます([積み場を呼び出す](summoning.md#the-top-edge))。
- ターミナルから:`tsumiba add report.pdf photos/`([コマンドライン](cli.md))。
- ブラウザから:[拡張機能](browser-extension.md)が画像(とページへのリンク)を送ります。

### コピーか、リンクか {#copy-or-link}

既定では、tsumiba は自分のフォルダーの中に**コピーを保存**します。元のファイルを移動・削除しても積み場の
中身は残ります。これから片付けるスクリーンショットやダウンロードには、こちらが向いています。

もう一つは**リンク**です。tsumiba は場所だけを覚え、何もコピーしません。二重に持ちたくない大きなファイルに
向いています。あとで元のファイルが無くなると、タイルには**見つかりません**と表示されます。黙って消える
ことはありません。モードは**設定 → ファイル**、`storage.mode`、またはコマンドごとの `tsumiba add --link` で
選べます。

**フォルダーは常にリンクになります。** フォルダーをコピーすると、うっかりホームディレクトリ全体を
コピーしかねないため、ドロップされたフォルダーはリンクになり、フォルダーのタイルとして表示されます。

変わらないことが 2 つあります。*リンク*を積み場から外しても、場所を忘れるだけで、**元のファイルは決して
削除されません**。そして、コピーはそれぞれ専用のディレクトリに入るので、同じ名前の別のファイルを 2 つ追加しても
両方が残ります。

## タイル {#the-tiles}

各タイルには、画像の**サムネイル**(8 MiB までの PNG・JPEG・GIF・WebP。それより大きい画像やほかの形式は、
色付きの種類バッジになります。6000 万画素の写真を 64 ピクセルを描くためだけにデコードすると、パネル全体が
固まってしまうためです)、名前、サイズが表示されます。ピンの印はピン留め(ピン留めされたファイルは先頭に
並びます)、矢印はリンクを表します。

- **クリック**でタイルを選択、**ダブルクリック**で既定のプログラムでファイルを開きます。
- **ホバー**すると、フルネーム、サイズ、経過時間、取得元のアドレス(ブラウザから来たファイルの場合)、
  リンクの場合は実際の場所が表示されます。
- **右クリック**でメニューが開きます。

| 項目 | 動作 |
| --- | --- |
| **開く** | 既定のプログラムで開く |
| **フォルダーで表示** | エクスプローラー、Finder、ファイルマネージャーで、選択した状態で表示する |
| **ファイルをコピー** | ファイルそのものをクリップボードに入れる。ファイルマネージャー、メール作成画面、チャットに貼り付けられる |
| **パスをコピー** | フルパスをクリップボードに入れる |
| **コピーを保存…** | 保存先を尋ねて、そこへコピーする |
| **名前を変更** | 名前を変える(リンクの場合は、積み場上の名前だけ) |
| **ピン留め / ピン留めを外す** | 先頭に固定する |
| **積み場から外す** | 外す(コピーはゴミ箱へ、リンクは場所を忘れるだけ) |

*ファイルをコピー*と*コピーを保存…*は、フォルダーには表示されません。

テキスト欄にキーボードがないときは、<kbd>Delete</kbd>(または <kbd>Backspace</kbd>)で、選択中のタイルを外せます。

## 外す、そしてゴミ箱 {#removing-and-the-trash}

コピーを外すと、**ゴミ箱フォルダー**に移され、30 日経つと消去されるまでそこに残ります。メッセージで 6 秒間は
**元に戻す**ことができ、その後でも手作業で戻せます([データと同期](data-and-sync.md#the-trash))。
リンクを外すと場所を忘れるだけで、こちらも同じように元に戻せます。

## ファイルを外へドラッグする {#dragging-files-out}

> [!WARNING]
> **まだできません。** タイルを積み場からほかのアプリケーションへドラッグして取り出すことは、現時点では
> サポートしていません。

tsumiba が使っているウィンドウツールキット(egui/eframe)は、ほかのプログラムからのドラッグを*受け取る*ことは
できますが、ネイティブのドラッグを*開始*することはできません。きちんと実現するには、Windows(OLE)、
macOS(NSDraggingSource)、X11(XDND)、Wayland(data-device のオファー)それぞれの専用コードが必要で、
これは今後の課題です。それまでは、次の 3 つの方法なら 1〜2 クリックでファイルを取り出せます。

1. **フォルダーで表示**を選び、ファイルマネージャーからドラッグする。
2. **ファイルをコピー**して、必要な場所に貼り付ける。
3. **コピーを保存…**を使う。

ドラッグで取り出すことが一番の目的なら、まさにそのために作られた [yeet](https://github.com/hjosugi/yeet)
(Wayland と Windows)や Yoink(macOS)があります。
