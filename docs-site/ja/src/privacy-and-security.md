# プライバシーとセキュリティ {#privacy-and-security}

## プライバシー {#privacy}

- **アカウントも、クラウドも、テレメトリもありません。**tsumiba は、あなたのメモ・ファイル・あなたに
  関する情報を、どこにも送りません。
- **外向きの接続はありません。**プログラムには HTTP クライアントが含まれていますが、使われるのは
  `127.0.0.1` にある*自分の* tsumiba に到達するため(コマンドラインからアプリへ)だけです。更新の確認も
  しませんし、どのサーバーにも接続しません。更新は、あなたが自分の意思で行うものです。
- **ブラウザ拡張**が通信するのは `127.0.0.1` だけです。ページのタイトル・アドレス・選択範囲を読むのは、
  送るように頼んだときだけです。
- **このドキュメントサイト**も、第三者へのリクエストを一切行いません。Web フォントも、解析も、
  ほかから読み込むスクリプトもありません。
- データは、あなたが選んだフォルダーの普通のファイルです([データと同期](data-and-sync.md))。
  **暗号化はされません**。ホームフォルダーのほかの部分と同じ程度に私的です。重要な場合は、ディスク全体の
  暗号化を使ってください。

## 何が待ち受けていて、何が守っているか {#what-listens-and-what-protects-it}

アプリが動いている間は、コマンドラインとブラウザ拡張のために、**`127.0.0.1:47821`**(設定可能。
`api.enabled = false` でオフ)で待ち受けます。ループバックインターフェースだけなので、ほかのコンピューター
から到達されることはありません。

それでもループバックには、コンピューター上のあらゆるプログラムと、ブラウザ経由で、開いたあらゆる Web
ページが到達できます。そのため API は守られています(詳細は [HTTP API](api.md#security-model))。

| 層 | 防ぐもの |
| --- | --- |
| **`Host`** ヘッダーが、ループバックと正しいポートを指していること | DNS リバインディング:ドメインが `127.0.0.1` に切り替えられる悪意あるサイト |
| **`Origin`** ヘッダーは、あるならブラウザ拡張であること | 通常の Web ページ全般。たとえトークンを何らかの形で知っていたとしても |
| **ベアラートークン**。システムの乱数生成器による 256 ビットで、一定時間で比較される | それ以外のすべて:ほかのローカルユーザー、ファイルにアクセスできないほかのプログラム、総当たり |

トークンは設定フォルダーの `token` にあり、Linux と macOS ではあなただけが読めます。Web ページに送られる
ことはなく、拡張機能は自分のストレージにコピーを持ちます。`tsumiba token --regenerate` で置き換えられます。

## トークンの価値 {#what-the-token-is-worth}

**トークンは、積み場のパスワードのように扱ってください。**これを持つ人は、API を通じて、メモとファイルの
読み取り・追加・変更・削除ができます。さらに、API はパスでファイルを*取り込める*ため、*あなた*が読める任意の
ファイルを積み場へコピーさせ、それを読み戻すこともできます。これは、あなたとして動くどんなプログラムでも
直接できることと同じ範囲で、実際の境界はそこにあります。

- **あなたとして**動いているプログラムは、tsumiba の助けなしに、メモのフォルダーもトークンのファイルも
  読めます。tsumiba はそれを防ごうとはしません。どのデスクトップアプリにも防げません。
- 同じマシンの**ほかのユーザー**はポートに接続できますが、トークンを読めない(Linux と macOS では権限が
  `0600`)ので、`401` になります。
- **Web ページ**は、トークンが調べられるよりも前に、Host と Origin の検査で止められます。

## 限界と、正直な注意点 {#limits-and-honest-caveats}

- データフォルダーは暗号化されず、tsumiba はその権限を変更しません。システムが新しいファイルに与える
  権限のままです。共有マシンなら、自分でフォルダーを私的にしてください。
- **Windows** では、トークンのファイルはあなたのプロファイルの中にあり、Windows がすでにあなただけに
  制限しています。追加の権限は設定しません。
- リリースは、まだ**コード署名も公証もされていません**。ダウンロードは `SHA256SUMS.txt` と照合してください。
  インストーラースクリプトは、これを自動で行います。
- ローカルのプログラムは、そのポートで何かが待ち受けていることを知ることができます(`GET /v1/ping` は、
  クライアントが tsumiba をほかのプログラムと区別できるよう、意図的に公開されています)。分かるのは
  名前とバージョンだけです。
- 拡張機能の任意の「すべてのサイト」の権限は、許可した場合でも、送ると決めた画像をダウンロードするため
  だけに使われます。

## 問題を報告する {#reporting-a-problem}

セキュリティ上の問題は、公開される前に修正できるよう、GitHub の
[プライベートな脆弱性報告](https://github.com/hjosugi/tsumiba/security/advisories/new)から非公開で報告して
ください(リポジトリの[セキュリティポリシー](https://github.com/hjosugi/tsumiba/blob/main/SECURITY.md)に
詳細があります)。通常のバグは[イシュー](https://github.com/hjosugi/tsumiba/issues)で歓迎します。
`tsumiba paths` の出力とログファイルの末尾の数行があると、報告がずっと役に立ちます。
